# Contributing to CAT (Commerce AI Trinity)

Welcome to the CAT project.

## Engineering Principles
- Documentation First
- AI-First Engineering
- Human Approval for Critical Actions
- Security by Design
- Modular Architecture
- Continuous Learning

## Branch Strategy
- main
- develop
- feature/*
- fix/*
- release/*
- hotfix/*

## Commit Convention
CAT follows Conventional Commits.

Examples:
- feat(core): add workflow engine
- docs(readme): improve project overview
- fix(memory): prevent duplicate entries

## Pull Requests
Every pull request should update documentation, pass tests, and follow architecture decisions.

## Security
Never commit secrets, API keys, or credentials.

## Definition of Done
- Code completed
- Tests passed
- Documentation updated
- Code reviewed
