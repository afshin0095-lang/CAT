# S09 — Data Classification

CAT classifies information before deciding retention, access, and logging behavior.

| Class | Examples | Default handling |
|---|---|---|
| Public | published affiliate metadata | ordinary access |
| Internal | operational metrics, non-public configuration | authenticated access |
| Confidential | business data, private reports | strict authorization + controlled logs |
| Secret | API keys, signing keys, passwords | secret manager; never ordinary logs |
| Restricted | security evidence or specially protected personal data | explicit policy + minimal retention |

Classification follows the most sensitive meaningful component. Derived data must not become less protected merely because it was generated by an agent.
