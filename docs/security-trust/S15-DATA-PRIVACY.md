# S15 — Data Privacy

CAT follows data minimization and purpose limitation.

- collect only data required for a declared capability;
- define retention before collecting sensitive information;
- separate operational telemetry from user/business data;
- redact sensitive values from logs;
- provide controlled deletion/anonymization paths where applicable;
- keep provider payload retention explicit;
- prevent agents from discovering unrelated private data through broad search.

Privacy controls must remain effective even when data is processed by AI models or external providers.
