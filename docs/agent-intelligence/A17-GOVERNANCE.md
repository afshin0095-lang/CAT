# A17 — Agent Governance

Governance controls who may create, modify, enable, disable, promote, or grant capabilities to agents.

Changes to agent definitions, prompts/templates, policies, tools, model routing, and budgets are versioned. Production promotion requires automated evaluation and, for high-impact changes, human approval.

No agent may alter its own registry record, policy profile, security boundary, or audit configuration. Emergency controls can disable an agent or capability globally without deleting historical evidence.
