# A18 — Human-in-the-Loop

Human approval is required where policy defines material impact or uncertainty.

Typical approval boundaries:

- financial transactions or irreversible financial configuration;
- production credential/security changes;
- destructive deletion;
- publication with legal/compliance implications;
- policy changes that expand autonomous authority;
- low-confidence actions where automated evidence is insufficient.

Approval requests contain the proposed action, evidence references, expected impact, risk flags, budget impact, and rollback/reversal information. Approval is a separate authorization event and expires according to policy.
