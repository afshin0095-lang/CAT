# O12 — SLO / SLA Model

SLOs define internal reliability objectives; SLAs are externally committed service levels.

Suggested CAT SLO dimensions:

- API availability;
- successful command processing;
- queue age;
- provider operation success rate;
- revalidation completion latency;
- data durability;
- recovery time.

Each SLO needs a measurement source, target window, exclusions, owner, and alert policy. Do not declare an SLA merely because an SLO exists.
