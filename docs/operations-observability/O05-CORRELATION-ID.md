# O05 — Correlation and Causation IDs

CAT distinguishes identifiers by purpose.

| ID | Scope |
|---|---|
| request_id | one inbound request |
| correlation_id | one business workflow across requests/jobs |
| trace_id | one distributed trace |
| span_id | one trace operation |
| command_id | one requested command |
| event_id | one emitted event |
| causation_id | event/command that caused another operation |
| idempotency_key | deduplication identity |

Identifiers are opaque, generated by trusted infrastructure, and validated at boundaries. A correlation ID does not grant authority and must never be treated as an authentication credential.
