Purpose
The `.ai` directory serves as the vendor-neutral AI workspace and permanent entry point for all AI systems (including OpenAI Codex, ChatGPT, Claude, Gemini, Kimi, Minimax, and future CAT AI Agents) working on the CAT repository. It defines how AI systems understand, navigate, and contribute to the project.

Scope
### How Every AI Assistant Should Start
1. Read this `README.md` file first to understand the workspace structure and guidelines.
2. Follow the context reading order defined below to load repository context systematically.
3. Check `PROJECT_STATUS.md` and `TASKS.md` for current project state and active tasks.
4. Strictly adhere to execution rules in `RULES.md` and guidelines in `PROMPT_GUIDELINES.md` and `STYLE_GUIDE.md`.
